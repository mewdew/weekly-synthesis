# Weekly Synthesis

A weekly consolidation of what I learn: scattered docs, experiments, and errors distilled into one coherent guide plus runnable code. Written by a senior frontend engineer (12 years in) learning across the stack and keeping up with AI.

Each topic lives in its own folder with a guide, runnable code, and a short README. Every folder is meant to work from a clean clone. If it doesn't, please open an issue.
